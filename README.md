# Centro de Prótesis Capilar Torremolinos

Sitio web estático optimizado para SEO local enfocado en prótesis capilar en Torremolinos.

## Estructura del proyecto

- `index.html` - Página principal con secciones de inicio, servicios, antes/después, precios, testimonios, FAQ y contacto.
- `assets/css/styles.css` - Estilos principales responsivos con paleta de colores crema y dorado.
- `assets/js/main.js` - Animaciones sutiles al hacer scroll.
- `assets/images/` - Carpeta de imágenes de ejemplo (usar placeholders o reemplazar por imágenes reales WebP).
- `sitemap.xml` - Mapa de sitio para SEO.
- `robots.txt` - Permite indexación.

## Cómo desplegar en Vercel

1. Crear un repositorio en GitHub con este código.
2. En Vercel, importar el repositorio.
3. Configurar `Framework Preset` en **Other** o **Static Site**.
4. Establecer la carpeta raíz como `/`.
5. Desplegar.

## Notas SEO

- Etiquetas meta completas y `og:` para redes sociales.
- `Schema.org` tipo `HairSalon` con datos locales de Torremolinos.
- Contenido en español optimizado para `prótesis capilar Torremolinos`.

## Reemplazar datos del negocio

Actualizar `index.html` con los valores reales:

- Nombre del negocio.
- Dirección exacta en Torremolinos.
- Teléfono / WhatsApp.
- Horario.
- URLs de redes sociales.
